# 🔎 Forum Monitor

Prosta aplikacja do **monitorowania forum** i wyszukiwania wybranych **ID**.

Program działa jako gotowa aplikacja `.exe` wraz z wymaganymi plikami `.dll` — **nie wymaga instalowania dodatkowych zależności**.

## ✨ Funkcje

* 🔍 Automatyczne monitorowanie forum
* 🆔 Wyszukiwanie wybranych ID
* ⚡ Szybkie wykrywanie nowych wpisów
* 🖥️ Gotowa aplikacja `.exe`
* 📦 Wymagane biblioteki `.dll` dołączone do programu
* 🚀 Proste uruchomienie
* 🔊 Dźwięk po wykryciu

## 📥 Uruchomienie

1. Pobierz **całe repozytorium** lub paczkę programu.
2. Upewnij się, że plik `.exe` znajduje się w tym samym folderze co wymagane pliki `.dll`.
3. Uruchom plik:

```text
ForumMonitorWpf.exe
```

> ⚠️ **Nie przenoś samego pliku `.exe` bez plików `.dll`** — są one wymagane do prawidłowego działania programu.

## 🆔 Wyszukiwanie ID

Forum Monitor pozwala monitorować forum pod kątem określonych **ID**.

Program automatycznie sprawdza nowe treści i wyszukuje w nich interesujące Cię wartości.

## 🛠️ Wymagania

* Windows 10 / 11
* Pliki `.exe` oraz `.dll` znajdujące się w odpowiednim folderze
* Dostęp do Internetu
